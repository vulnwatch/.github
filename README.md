# vulnwatch/.github

The profile of the [vulnwatch](https://github.com/vulnwatch) organization on
GitHub, the home of Sentinel. GitHub shows
[`profile/README.md`](profile/README.md) on the organization's page.

[`assets/avatar.svg`](assets/avatar.svg) is the source of the organization's
profile picture, Sentinel's shield on Sentinel's blue, and
[`assets/avatar.png`](assets/avatar.png) its 1024 × 1024 rendering, which the
organization's settings upload.
